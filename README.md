# Cinematic Portfolio — Starter

A dark editorial portfolio starter inspired by the cinematic portfolio style in the referenced Creativo video.

## Run

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Replace before publishing

- `src/main.jsx`: replace placeholder email, LinkedIn and GitHub URLs.
- Add real project links/case studies.
- `public/portrait.png` is the cinematic portrait generated for this portfolio.
- Replace Google Font imports with locally hosted fonts if you want a fully self-contained build.

## Build

```bash
npm run build
```
